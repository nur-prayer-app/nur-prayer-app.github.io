# Nur - Prayer Tracker

Releases and website for [Nur](https://nur-prayer-app.github.io).

![Version](https://img.shields.io/badge/version-1.2.4-blue)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Web%20%7C%20PWA-0078d4)

A Muslim prayer tracker with Hijri calendar, prayer times, qadaa management, and statistics.

- **Website:** https://nur-prayer-app.github.io
- **Web app (PWA):** https://nur-prayer-app.github.io/app/
- **Windows installer:** see [Releases](https://github.com/nur-prayer-app/nur-prayer-app.github.io/releases)
- **Source code:** https://github.com/nur-prayer-app/source (private)

## What lives here

| Path | Purpose |
|------|---------|
| `index.html` | Marketing / landing page |
| `app/` | Deployed web app (PWA) |
| `install.html` | Installer download page |
| `version.json` | In-app update check |
| `privacy.html` / `terms.html` / `contact.html` | Site pages |

This repo is updated by the source repo release workflow when a `v*` tag is pushed.
